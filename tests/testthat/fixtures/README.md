# Scientific reference fixtures

The retained fixtures are deterministic source-level scientific oracles. They
construct their own tiny inputs and do not encode compatibility fields.

| Fixture | Model/operator | Purpose | Owner | Tolerance | Regeneration |
|---|---|---|---|---|---|
| `st-bayesc-csr-reference.R` | ST SBayesC / CSR | scalar multichain and seed reference | `test-blr-extended-reproducibility.R` | exact, except documented timing/path normalization | generated by the embedded fixture functions |
| `st-bayesc-scheduled-csr-reference.R` | ST SBayesC / scheduled CSR | scheduler reproducibility | `test-blr-extended-reproducibility.R` | `1e-12` | generated by the embedded fixture functions |
| `st-bayesc-bed-reference.R` | ST BayesC / packed BED | packed-BED multichain reproducibility | `test-blr-extended-reproducibility.R` | `1e-12` | generated by the embedded fixture functions |
| `mt-bayesc-reference.R` | MT BayesC / dense reference | joint-chain and OpenMP reference | `test-blr-extended-reproducibility.R` | `1e-12` | generated by the embedded fixture functions |

Fixture values must not be regenerated during routine maintenance. A change is
allowed only for a demonstrated scientific correction with an independently
reviewed oracle.
