# MTBLR covariance design

## 1. Scope and repository baseline

This document completes the first covariance-design phase described in
`mtblr_redesign.md`. The work was performed from branch `master` at commit
`52d50219ead086245dc38cb5e5958a1403c78d1d`. The user-provided earlier Phase
3A checkpoint was `e11abdf9f2f49b03169449c680ae033df4992acf`; the repository had
advanced to the clean commit recorded above before this work began. No
production R interface, C++ sampler, generated interface,
schema, Methods page, or existing test was changed.

The first validation case used a shared marker-level state with $T=2$ traits.
The completed design extends that reduction to all four Cheng activity
patterns, persistent regional reference states, and heterogeneous independent
summary providers with provider-specific dense, CSR, and block-eigen
operators. The research prototype compares coherent augmentations with a
diagnostic reconstruction of the current BayesC covariance transition. It does
not promote the prototype to a package backend.

## 2. Current-source trace

The executable source currently has more than one meaning for the object named
`B` or `V_b` during a BayesC iteration.

| Operation | Current ownership | Observed behavior |
|---|---|---|
| Public MT dispatch | `R/mtblr-bed.R`, `R/mtblr-csr.R`, `R/mtblr-block-eigen.R` and shared adapters | Selects BayesC or BayesR and the likelihood operator before entering the common native core. |
| Shared BayesC core | `src/blr_mt_default_core_impl.h`, `run_mt_default_core()` | Maintains a latent `beta` matrix and a realised, state-masked effect matrix. |
| Marker transition | `src/mtblr.cpp`, `sampleBetaCPG_Mt_latent()` | Draws a complete latent vector for every BayesC marker. A null marker has a prior latent draw, while its realised effect is zero. |
| Latent covariance transition | `src/mtblr.cpp`, `sampleB_latent()` | Draws an inverse-Wishart matrix using all $M$ latent vectors and degrees of freedom `nub + M`. |
| Heuristic covariance transition | `src/mtblr.cpp`, `sampleBset()` and `sampleB()` | Uses active realised effects, trait-specific active counts, empirical shared-active cross-products, correlation shrinkage and positive-definite repair. |
| Iteration ordering | `src/blr_mt_default_core_impl.h` | A heuristic draw is followed by the all-marker latent draw used for marker updates; after marker updates another heuristic draw replaces it for traces, accumulation, the next iteration and output. |
| BayesR scaling | `src/blr_mt_default_core_impl.h`, `mt_bayesr_base_effects()` and the joint marker kernel | Active realised effects are divided by the square root of the component and marker multiplier before the covariance heuristic; null effects are stored as zero. |
| Raw and formatted covariance | shared core return and MT raw-to-fit formatter | The post-marker heuristic matrix, not the latent inverse-Wishart draw used by the marker transition, is accumulated and returned as the covariance trace/summary. |

The current BayesC transition is therefore not merely an alternative
inverse-Wishart parameterization. Marker probabilities use one covariance draw,
whereas the returned and next-iteration covariance is generated by another
transition. The prototype reproduces this scientifically relevant ordering.

There is also a scale-convention collision. `src/blr_mt_covariance_rng.h` uses
the standard inverse-Wishart construction described below. In contrast, current
R prior calibration makes a diagonal quantity appropriate for the scalar
inverse-chi-squared heuristic, which multiplies it by `nub`; `sampleB_latent()`
uses the same object directly as an inverse-Wishart scale. Those two uses cannot
both encode the same requested prior mean when $T=2$.

## 3. Authoritative notation and interpretation

For marker $j$,

$$
\boldsymbol{\beta}_j
$$

is the latent slab-effect vector,

$$
\boldsymbol{\delta}_j
$$

is the inclusion or mixture state, and

$$
\boldsymbol{\alpha}_j
=
\boldsymbol{\delta}_j\odot\boldsymbol{\beta}_j
$$

is the realised marker-effect vector. For the shared binary state considered
first, multiplication by $\boldsymbol{\delta}_j$ reduces to multiplication by
the scalar $\delta_j$.

The coherent interpretation supported by both derivations is

$$
V_b
=
\operatorname{Var}
\left(
\boldsymbol{\beta}_j
\mid
\text{non-null component}
\right).
$$

This is not the covariance of $\boldsymbol{\alpha}_j$ across all markers. With
independent shared BayesC states and zero prior mean, that prior covariance is
$\pi V_b$. Nor is $V_b$ genomic covariance: for a realised effect matrix
$A$, genomic covariance on a common genotype sample is $A^\top X^\top XA/N$.

## 4. Full joint probability model

Let $Y$ be $N\times T$, $X$ be $N\times M$, and $A$ be $M\times T$ with row
$\boldsymbol{\alpha}_j^\top$. With fixed positive-definite residual covariance
$V_e$,

$$
Y\mid A,V_e
\sim
\operatorname{MN}_{N\times T}(XA,I_N,V_e).
$$

Shared-state BayesC is

$$
\delta_j\mid\pi
\sim
\operatorname{Bernoulli}(\pi),
$$

$$
\boldsymbol{\beta}_j\mid V_b
\sim
N_T(\mathbf 0,V_b),
$$

$$
\boldsymbol{\alpha}_j
=
\delta_j\boldsymbol{\beta}_j.
$$

The prototype treats $\pi$ and $V_e$ as fixed to isolate covariance design. It
uses

$$
V_b\sim\operatorname{IW}_T(\nu_0,\Psi_0).
$$

These choices define the joint density before an augmentation is selected.

## 5. Exact inverse-Wishart parameterization

The convention is

$$
p(V\mid\nu,\Psi)
=
\frac{|\Psi|^{\nu/2}}
{2^{\nu T/2}\Gamma_T(\nu/2)}
|V|^{-(\nu+T+1)/2}
\exp
\left\{
-\frac{1}{2}\operatorname{tr}(\Psi V^{-1})
\right\}.
$$

The distribution is proper for $\nu>T-1$; its mean exists for $\nu>T+1$ and
is

$$
\mathbb E(V)=\frac{\Psi}{\nu-T-1}.
$$

Therefore, a desired prior mean $V_0$ maps to

$$
\Psi_0=(\nu_0-T-1)V_0.
$$

The standalone R draw is

```r
W <- rWishart(1L, df = nu, Sigma = solve(Psi))[, , 1L]
V <- solve(W)
```

because $W\sim W_T(\nu,\Psi^{-1})$ implies
$W^{-1}\sim\operatorname{IW}_T(\nu,\Psi)$. The prototype checks dimensions,
finiteness, symmetry, positive definiteness and the degrees-of-freedom boundary
before drawing.

## 6. Full latent derivation

Let $R_j=Y-\sum_{\ell\ne j}x_\ell\boldsymbol{\alpha}_\ell^\top$. Define

$$
Q_j
=
V_b^{-1}
+
(x_j^\top x_j)V_e^{-1},
$$

$$
h_j
=
V_e^{-1}R_j^\top x_j.
$$

Conditional on $\delta_j=1$,

$$
\boldsymbol{\beta}_j\mid\delta_j=1,-
\sim
N_T(Q_j^{-1}h_j,Q_j^{-1}).
$$

Integrating that vector gives

$$
\log\operatorname{BF}_j
=
\frac{1}{2}
\left\{
\log|V_b^{-1}|
-
\log|Q_j|
+
h_j^\top Q_j^{-1}h_j
\right\},
$$

and

$$
\Pr(\delta_j=1\mid-)
=
\operatorname{logit}^{-1}
\left\{
\operatorname{logit}(\pi)+\log\operatorname{BF}_j
\right\}.
$$

The full-latent block draws the state from this integrated probability, draws
the displayed posterior if active, and draws
$\boldsymbol{\beta}_j\sim N_T(0,V_b)$ if null. Given all retained vectors,

$$
V_b\mid\boldsymbol{\beta}_{1:M}
\sim
\operatorname{IW}_T
\left(
\nu_0+M,
\Psi_0+
\sum_{j=1}^M
\boldsymbol{\beta}_j\boldsymbol{\beta}_j^\top
\right).
$$

Null-marker latent vectors enter this augmented conditional, but integrate out:

$$
\int N_T(\boldsymbol{\beta}_j;0,V_b)
\,d\boldsymbol{\beta}_j
=1.
$$

Thus they add no factor to the marginal likelihood for $V_b$. Their only role
is augmentation. This proves target coherence, not good mixing: many refreshed
prior vectors can make consecutive $V_b$ draws strongly dependent.

## 7. Active-only or partially collapsed derivation

In the active-only state space, $\boldsymbol{\beta}_j$ exists only when
$\delta_j=1$. The marker block must first use the same integrated Bayes factor
as above. If the sampled state is active it draws the conditional Normal; if it
is null there is no slab vector. After every marker block,

$$
V_b\mid\{\boldsymbol{\beta}_j:\delta_j=1\}
\sim
\operatorname{IW}_T
\left(
\nu_0+M_+,
\Psi_0+
\sum_{j:\delta_j=1}
\boldsymbol{\beta}_j\boldsymbol{\beta}_j^\top
\right),
$$

where $M_+=\sum_j\delta_j$. An inactive marker contributes neither an outer
product nor a degree of freedom because its latent vector has been integrated
out of this state space.

The order is essential: update each joint state/effect block using the current
$V_b$, then update $V_b$ using the resulting active vectors. It would be invalid
to store null vectors as zeros, use the active-only cross-product, and retain
the full-latent degrees of freedom $\nu_0+M$.

For the shared binary state, this sampler is fully collapsed only with respect
to null slab vectors and remains conjugate. The complete Cheng extension in
Sections 18--24 supplies the required partial augmentation for trait-specific
patterns: completely null markers remain collapsed, whereas missing
coordinates of a non-null marker are conditionally completed before using a
full $T\times T$ outer product. Simply inserting zero coordinates would change
the model.

## 8. BayesR multiplier derivation

The scale convention must be fixed before writing the covariance statistic.
The standalone shared-component BayesR prototype stores the scaled complete
vector $\boldsymbol{\theta}_j$ with

$$
\boldsymbol{\theta}_j\mid k_j,V_b
\sim N_T(0,\gamma_{k_j}q_jV_b),
\qquad
\boldsymbol{\alpha}_j
=
\boldsymbol{\theta}_j
$$

for a shared all-traits component with $k_j>0$, $\gamma_{k_j}>0$, and
$q_j>0$. The null state remains exact. Under this stored-effect convention,
the update is

$$
V_b\mid-
\sim
\operatorname{IW}_T
\left(
\nu_0+M_+,
\Psi_0+
\sum_{j:k_j>0}
\frac{
\boldsymbol{\theta}_j\boldsymbol{\theta}_j^\top
}{
\gamma_{k_j}q_j
}
\right).
$$

An equivalent base-vector implementation may define
$\boldsymbol{\theta}_j=\sqrt{\gamma_{k_j}q_j}\,\boldsymbol{\beta}_j$ with
$\boldsymbol{\beta}_j\sim N_T(0,V_b)$ and store
$\boldsymbol{\beta}_j$. It then contributes the base outer product directly:

$$
V_b\mid-
\sim
\operatorname{IW}_T
\left(
\nu_0+M_+,
\Psi_0+
\sum_{j:k_j>0}
\boldsymbol{\beta}_j\boldsymbol{\beta}_j^\top
\right).
$$

Each active $T$-vector contributes one degree of freedom, not $T$ degrees of
freedom. The multiplier must be removed exactly once: never divide a stored
base vector again, and never omit division for a stored scaled vector. The
prototype names and returns the stored object as $\boldsymbol{\theta}_j$,
checks the scaled-vector identity directly for unequal $q_j$, and enumerates
BayesR component states at known $V_b$ independently of the sampler. The
$q_j=1$ case is a reduction and is not the complete scale contract.

The current source stores component-scaled latent and realised effects, then
`mt_bayesr_base_effects()` divides them by
$\sqrt{\gamma_{k_j}q_j}$ before covariance calculations
(`src/blr_mt_bayesr_kernel_impl.h:165-184`). The redesign should make the base
latent vector the canonical chain-state object so this conversion cannot be
applied twice.

## 9. Current or hybrid transition reconstruction

`mtblr_current_hybrid.R` reconstructs the current shared-state BayesC ordering:

1. draw a heuristic active-effect covariance;
2. draw a separate all-marker latent inverse-Wishart covariance using
   $\nu_0+M$;
3. update marker states and latent/realised effects using that latent covariance;
4. draw a second heuristic active-effect covariance;
5. retain the second heuristic covariance as the trace and output quantity.

The heuristic diagonal uses active sums of squares and trait-specific active
counts. Off-diagonals use only shared-active markers, two layers of shrinkage,
a correlation clamp and a positive-definite eigenvalue repair. These are useful
stabilization ideas, but together they are not the full conditional of the
stated inverse-Wishart model. The prototype retains both the covariance used by
the marker transition and the covariance reported by the hybrid so the
difference is observable.

For current BayesR, null marker effects are zeros and component/marker scaling
is removed to form base effects before the active-effect heuristic. The present
prototype verifies the correct BayesR conjugate statistic but does not pretend
that the BayesC hybrid reconstruction is an exact reproduction of every BayesR
branch.

## 10. Exact and numerical reference design

For known $V_b$, the reference enumerates all $2^M$ BayesC states and all
$(K+1)^M$ BayesR states for $M\le2$. For each state it integrates the active
Normal effects analytically:

$$
\operatorname{vec}(Y)\mid\boldsymbol{\delta},V_b
\sim
N
\left(
0,
V_e\otimes I_N+H_{\boldsymbol{\delta}}
G_{\boldsymbol{\delta}}
H_{\boldsymbol{\delta}}^\top
\right).
$$

Normalizing those independently evaluated state densities gives exact state
probabilities, PIPs, posterior means of realised effects and predictions.

For unknown $V_b$ with $T=2$ and $M=1$, the independent numerical reference
uses

$$
V_b
=
\begin{pmatrix}
s_1^2 & \rho s_1s_2\\
\rho s_1s_2 & s_2^2
\end{pmatrix},
$$

on a regular grid in $(\log s_1,\log s_2,\operatorname{atanh}\rho)$. The
Jacobian for the three unique covariance elements is

$$
4s_1^3s_2^3(1-\rho^2).
$$

The grid evaluates the inverse-Wishart density and state-integrated likelihood
directly. Two resolutions are compared, and boundary mass is checked. This is
a numerical reference, not an exact covariance posterior.

## 13. Mixing and computational comparison

With 10,000 retained draws per chain and three seeds, the active-only
$V_{b,11}$ chain had mean lag-1 autocorrelation $0.020$ and approximate mean ESS
$9,426$; full latent had lag-1 autocorrelation $0.292$ and ESS $5,354$. Mean
elapsed times were 19.4 seconds and 21.7 seconds, respectively. The hybrid took
29.4 seconds in this transparent R implementation; its low covariance
autocorrelation is not evidence of validity because it samples a different
quantity.

An uninformative-genotype sensitivity case isolated inactive-marker
augmentation at $\pi=0.03$:

| Markers | Transition | mean active | mean $V_{b,11}$ | lag 1 | ESS of 4,000 |
|---:|---|---:|---:|---:|---:|
| 2 | Full latent | 0.0668 | 0.2928 | 0.248 | 2,529 |
| 2 | Active only | 0.0535 | 0.3040 | -0.013 | 4,000 |
| 12 | Full latent | 0.3540 | 0.3001 | 0.799 | 612 |
| 12 | Active only | 0.3595 | 0.3029 | 0.063 | 3,554 |

Both samplers retain the prior covariance marginally, as they should. Only the
full-latent dependency worsens sharply with the number of mostly inactive
markers. This directly addresses sparse inclusion rather than assuming a speed
advantage.

## 14. Implications for output semantics

Production output should expose actual retained draws from the covariance
transition that drives the marker sampler. Under the recommended interpretation:

- `V_b` is the non-null slab covariance;
- posterior covariance summaries are means or final values of those sampled
  matrices, not a post hoc active-effect replacement;
- realised-marker covariance, genomic covariance and covariance of genetic
  values are separate derived quantities and must use different names;
- BayesR reports the common base covariance after accounting for $\gamma_k$
  (and $q_j$ where applicable);
- no-active-marker iterations draw $V_b$ from its prior under active-only
  augmentation and remain statistically defined.

The future output contract should state whether a covariance field is a draw,
a posterior mean of draws, or a heuristic empirical summary. One field should
not change meanings within an iteration.

## 15. Recommended production transition

**Recommendation: use active-only or partially collapsed augmentation as the
production foundation for the complete Cheng MT-BayesC$\Pi$ model.** Collapse
the complete latent vector for a null marker, sample each non-null activity
pattern and its active effect coordinates from the integrated marker
conditional, and conditionally complete every inactive coordinate of a
non-null marker before updating $V_b$. Draw $V_b$ once per completed MCMC
iteration from

$$
V_b\mid-
\sim
\operatorname{IW}_T
\left(
\nu_0+M_+,
\Psi_0+
\sum_{j:\boldsymbol{\delta}_j\ne\mathbf 0}
\boldsymbol{\beta}_j\boldsymbol{\beta}_j^\top
\right),
$$

where $M_+$ is the number of non-null markers and every
$\boldsymbol{\beta}_j$ in the sum is a complete latent vector. For $T=2$, this
means:

- $(0,0)$: integrate out the complete latent vector;
- $(1,0)$: sample trait 1 and conditionally complete trait 2;
- $(0,1)$: sample trait 2 and conditionally complete trait 1;
- $(1,1)$: sample the complete likelihood-informed vector.

The initial production implementation should use a joint categorical draw over
the declared activity patterns. Coordinate transitions target the same model
when constructed correctly on a connected one-coordinate state graph, but the
validated imbalanced-pattern example shows
that they can mix poorly when movement between high-probability states requires
passing through low-probability intermediate patterns.

The recommendation is based on:

- **posterior correctness:** exact enumeration, numerical integration and the
  full-latent equivalence all support the same marginal target;
- **sparse-inclusion mixing:** removing irrelevant null latent vectors avoids
  the observed augmentation dependence as $M$ grows;
- **BayesR extensibility:** under scaled-effect storage, the sufficient
  statistic has the transparent $1/(\gamma_kq_j)$ form;
- **trait-specific patterns:** conditional completion gives a principled route
  to learning off-diagonal covariance without treating zeros as observations;
- **implementation complexity:** it requires a carefully ordered marker block,
  but avoids storing and refreshing $M$ null vectors;
- **testability:** exact state enumeration and conjugate covariance identities
  provide independent small-case oracles;
- **semantics:** every retained $V_b$ draw has the advertised non-null slab
  interpretation;
- **outputs:** the sampler's actual covariance draws can be returned without a
  heuristic replacement.

Cheng full-latent augmentation remains the scientific reference implementation
and oracle. It is not recommended as production merely because it is easy to
derive: its sparse-marker mixing degradation is substantial. The current
production hybrid is not recommended because the marker transition and
returned covariance do not form one documented posterior transition.

## 16. Remaining limitations and open decisions

1. The prototype validates the covariance and activity-pattern blocks in
   isolation. Their production interaction with sampled $V_e$ and sampled or
   fixed $\boldsymbol{\Pi}$ must preserve the same joint target and update
   ordering.
2. The current marker-weight calculation uses only diagonal elements of
   $V_e^{-1}$ even when a full residual covariance is present. The production
   transition must either use the declared full residual model or document and
   test a restricted diagonal likelihood.
3. MAF-S, annotation and other marker-specific variance multipliers introduce
   $q_j$. The declared storage convention and route-specific normalization must
   ensure that component and marker scales are removed exactly once in the
   $V_b$ sufficient statistic.
4. Prior calibration must migrate from the current scalar inverse-chi-squared
   heuristic convention to the inverse-Wishart convention in Section 5. The
   public prior-mean mapping and migration of existing results require an
   explicit decision.
5. Heterogeneous independent summary providers are now validated at the
   operator level, but an overlap-aware likelihood still requires a declared
   cross-provider summary-score covariance contract.
6. Independent regional inverse-Wishart states are a proper reference model,
   not the recommended unrestricted production default. Regional partial
   pooling or shared covariance-template libraries must be specified for
   low-information regions.
7. Joint pattern enumeration grows as $2^T$ for BayesC and more rapidly after
   adding BayesR scales or covariance templates. Structured pattern sets,
   trait groups, factor models or gated coordinate transitions are required for
   larger $T$.
8. The low-dimensional numerical grids and standalone simulations are exact or
   controlled reference tools for the declared small cases; they are not a
   general covariance-inference engine.

## 17. Proposed next implementation milestone

The next phase should be a separate, incremental production task built from the
validated design rather than another derivation phase:

1. approve the inverse-Wishart prior-mean migration and public parameter
   crosswalk;
2. establish a representation-neutral MT scientific kernel with one
   authoritative covariance state per chain and iteration;
3. implement MT-BRR as the dense covariance reference reduction;
4. implement the complete Cheng MT-BayesC$\Pi$ joint pattern transition with
   null collapse and conditional completion;
5. return the actual sampled $V_b$ draws and remove the in-iteration heuristic
   replacement from the new policy;
6. validate the kernel against exact $M=1$ and $M=2$ pattern probabilities,
   zero-active cases, conditional-completion moments and the Cheng full-latent
   reference;
7. connect the same scientific transition to the common-sample individual-level
   likelihood and heterogeneous independent-provider summary likelihood;
8. validate dense, CSR and provider-specific full-rank block-eigen reductions,
   while treating retained-rank eigen operators as explicit approximations;
9. preserve distinct $C_{dt}$, $N_{dt}$, marker maps and operator provenance for
   every trait and provider;
10. defer regional production covariance, pattern-by-scale BayesR, covariance
    templates and overlap-aware summaries to controlled later milestones after
    the global Cheng implementation is accepted.

This milestone will intentionally change posterior covariance draws and output
semantics relative to the current hybrid. It therefore requires explicit API,
raw-schema, formatted-output and result-migration notes. It is not part of this
research prototype.

## 18. General Cheng MT-BayesC$\Pi$ extension

Sections 1--17 established the shared-state special case containing only
$(0,0)$ and $(1,1)$. This section extends that result to the complete Cheng et
al. (2018) activity-pattern model. For $T=2$ the state ordering used by the
prototype and current public R pattern constructor is

$$
\mathcal S
=
\left\{
(0,0),(1,0),(0,1),(1,1)
\right\}.
$$

For marker $j$,

$$
\boldsymbol{\delta}_j
=
(\delta_{j1},\ldots,\delta_{jT}),
\qquad
D_j=\operatorname{diag}(\boldsymbol{\delta}_j),
$$

$$
\boldsymbol{\beta}_j\mid V_b
\sim
N_T(\mathbf 0,V_b),
\qquad
\boldsymbol{\alpha}_j=D_j\boldsymbol{\beta}_j,
$$

and

$$
\Pr(\boldsymbol{\delta}_j=s\mid\boldsymbol{\Pi})=\Pi_s,
\qquad
\boldsymbol{\Pi}\sim\operatorname{Dirichlet}(\mathbf a_\Pi).
$$

Together with the matrix-normal likelihood and inverse-Wishart prior in
Sections 4--5, this is the complete prototype joint model:

$$
p(Y,\boldsymbol{\alpha},\boldsymbol{\beta},\boldsymbol{\delta},V_b,
\boldsymbol{\Pi})
=
p(Y\mid\boldsymbol{\alpha},V_e)
p(V_b)p(\boldsymbol{\Pi})
\prod_{j=1}^M
\Pi_{\boldsymbol{\delta}_j}
N_T(\boldsymbol{\beta}_j;0,V_b)
\mathbf 1\{\boldsymbol{\alpha}_j=D_j\boldsymbol{\beta}_j\}.
$$

This makes $V_b$ the covariance of a complete latent slab vector. The
covariance of realised effects depends additionally on the activity-pattern
distribution and is not $V_b$.

### 18.1 Integrated pattern probabilities

Let $R_j$ be the partial residual excluding marker $j$, let $A_s$ index the
active traits in pattern $s$, and let $S_s$ select those coordinates. Define

$$
g_s
=
S_s^\top V_e^{-1}R_j^\top x_j,
$$

$$
C_s
=
V_{b,A_sA_s}^{-1}
+
(x_j^\top x_j)
S_s^\top V_e^{-1}S_s.
$$

For a non-null pattern, the active subvector has conditional distribution

$$
\boldsymbol{\beta}_{j,A_s}\mid s,-
\sim
N
\left(
C_s^{-1}g_s,C_s^{-1}
\right).
$$

After integrating it, the unnormalized pattern weight is

$$
w_s
=
\Pi_s
\exp
\left[
\frac12
\left\{
\log|V_{b,A_sA_s}^{-1}|
-
\log|C_s|
+
g_s^\top C_s^{-1}g_s
\right\}
\right].
$$

For the null pattern the exponential factor is one. Normalizing the four
weights gives the joint categorical transition. This active-subspace derivation
also handles non-diagonal $V_e$; replacing $V_e^{-1}$ by only its diagonal is a
different likelihood calculation.

### 18.2 Conditional completion

For a partially active pattern, partition the latent vector into active and
inactive coordinates. After drawing the likelihood-informed active subvector,
the inactive subvector must be drawn from

$$
\boldsymbol{\beta}_{j,I}
\mid
\boldsymbol{\beta}_{j,A},V_b
\sim
N
\left(
V_{b,IA}V_{b,AA}^{-1}\boldsymbol{\beta}_{j,A},
V_{b,II}-V_{b,IA}V_{b,AA}^{-1}V_{b,AI}
\right).
$$

The prototype independently simulated this conditional for pattern $(1,0)$.
Its empirical mean and variance agreed with the displayed formula within
$0.012$ and $0.015$, respectively. An inactive coordinate is therefore neither
zero nor an independent draw when $V_b$ has nonzero off-diagonal covariance.

### 18.3 Two coherent augmentations

The Cheng full-latent reference keeps a complete vector for every marker. It
draws inactive coordinates by conditional completion and uses

$$
V_b\mid\boldsymbol{\beta}
\sim
\operatorname{IW}_T
\left(
\nu_0+M,
\Psi_0+
\sum_{j=1}^M
\boldsymbol{\beta}_j\boldsymbol{\beta}_j^\top
\right).
$$

The validated partially collapsed transition integrates the complete vector
only for pattern $(0,0)$. Every non-null marker is completed to dimension $T$,
and

$$
V_b\mid\boldsymbol{\beta},\boldsymbol{\delta}
\sim
\operatorname{IW}_T
\left(
\nu_0+M_+,
\Psi_0+
\sum_{j:\boldsymbol{\delta}_j\ne\mathbf 0}
\boldsymbol{\beta}_j\boldsymbol{\beta}_j^\top
\right).
$$

The valid schedule is: calculate a pattern probability with the marker effect
integrated out; draw the pattern; draw the active effect; conditionally complete
inactive coordinates for a non-null pattern; update all other markers; update
$\boldsymbol{\Pi}$; then update $V_b$ once. No subsequent transition may
condition on a null latent vector that was integrated out earlier in that
schedule.

The two samplers target the same marginal posterior. Completely null latent
vectors integrate to one, while the completed vector density for every non-null
pattern is retained in both representations. Exact configuration enumeration
and the Monte Carlo comparisons below verify the result rather than relying on
this argument alone.

### 18.4 Pattern-probability transition

With $n_s=\sum_j\mathbf 1(\boldsymbol{\delta}_j=s)$,

$$
\boldsymbol{\Pi}\mid\boldsymbol{\delta}
\sim
\operatorname{Dirichlet}
\left(
\mathbf a_\Pi+\mathbf n
\right).
$$

For fixed $V_b$ and $M\le2$, the reference integrates
$\boldsymbol{\Pi}$ analytically through the Dirichlet-multinomial mass and
enumerates all pattern configurations. Thus its learned probability results do
not reuse either MCMC transition.

### 18.5 Joint and coordinate transitions

The joint transition normalizes all four weights above. The coordinate
transition updates one indicator conditional on the other by normalizing the
same collapsed weights over the two compatible patterns. After a complete
coordinate sweep it draws and completes the latent vector for the final
pattern. Both kernels therefore leave the same collapsed state conditional
invariant.

This statement requires the declared pattern graph to be connected under
one-coordinate moves. The complete four-pattern space satisfies that
condition. A restricted space containing only $(0,0)$ and $(1,1)$ is
disconnected and makes coordinate updating reducible, so the prototype rejects
that combination informatively. Joint categorical updating remains valid for
the same scientifically declared restricted space.

The coordinate kernel can nevertheless cross poorly between $(0,0)$ and
$(1,1)$ because it must pass through a low-probability intermediate pattern.
With fixed probabilities $(0.49,0.01,0.01,0.49)$, the joint kernel had lag-1
autorrelation $0.0069$ and ESS $7,398$ from 7,500 draws for the pleiotropic-state
indicator. The coordinate kernel had lag-1 autocorrelation $0.903$ and ESS
$266$, with only 235 direct null/both changes versus 4,160 for the joint kernel.

## 20. Current four-pattern source reconstruction

Current public `.mtblr_models()` constructs all $2^T$ binary patterns by
default; for $T=2$ its ordering is exactly $(0,0),(1,0),(0,1),(1,1)$. A
`"restrictive"` option produces only the shared-state special case. BayesC
therefore already intends the general trait-pattern model; the first prototype
was a validation reduction, not the complete current state geometry
(`R/mtblr-csr.R:198-212`).

In `sampleBetaCPG_Mt_latent()` the current source:

- performs one joint categorical draw over the supplied patterns;
- stores a complete latent `beta` and a masked realised `b` separately;
- adds likelihood precision only for active coordinates;
- draws all coordinates jointly from the resulting Normal, which conditionally
  completes inactive coordinates through the off-diagonal prior precision;
- gives the null pattern a prior-distributed complete latent vector;
- increments one global pattern-count vector and applies a global Dirichlet
  update through `samplePi()`.

These statements follow the executable storage and transition at
`src/mtblr.cpp:2952-3145`; the pattern normalization and draw are at
`src/mtblr.cpp:3033-3076`, and the separate complete `beta` and masked `b`
assignments are at `src/mtblr.cpp:3112-3145`. The global gamma-normalization
and count reset used by `samplePi()` are at `src/mtblr.cpp:317-336`.

The pattern probability update uses an implicit Dirichlet$(1,\ldots,1)$ prior
for ordinary BayesC unless an internal model prior is supplied. Public
`pimodels` initializes the simplex but is not, by itself, a general public
Dirichlet-prior interface. Ordinary MT BayesR instead estimates a full global
joint pattern-by-component simplex. MT BayesRC uses its documented component
probability times conditional non-null sharing factorization.

Two caveats remain. First, the current marker weight calculation uses only
diagonal elements of $V_e^{-1}$ even when a full residual covariance object is
present (`src/mtblr.cpp:2971-3004,3083-3090`). Second, the coherent
complete-vector transition is embedded in the
hybrid covariance schedule reconstructed in Sections 2 and 9. Correct latent
completion does not make that surrounding covariance transition coherent.

## 21. Region and set-specific covariance

### 21.1 Explicit regional model

For a declared region map $r(j)$,

$$
\boldsymbol{\delta}_j\mid r(j)=r
\sim
\operatorname{Categorical}(\boldsymbol{\Pi}_r),
$$

$$
\boldsymbol{\beta}_j\mid r(j)=r,V_{b,r}
\sim
N_T(0,V_{b,r}),
\qquad
\boldsymbol{\alpha}_j=D_j\boldsymbol{\beta}_j.
$$

Independent reference priors are

$$
\boldsymbol{\Pi}_r\sim\operatorname{Dirichlet}(\mathbf a_{\Pi,r}),
\qquad
V_{b,r}\sim\operatorname{IW}_T(\nu_{0,r},\Psi_{0,r}).
$$

A shared-global pattern state instead declares one distinct prior,

$$
\boldsymbol{\Pi}
\sim
\operatorname{Dirichlet}(\mathbf a_{\Pi,\mathrm{global}}).
$$

It is not obtained by replicating $\mathbf a_\Pi$ over $R$ regions and then
summing the rows, which would silently replace the prior by
$R\mathbf a_\Pi$.

Under full augmentation, region $r$ uses its $M_r$ complete vectors and degrees
of freedom $\nu_{0,r}+M_r$. Under null collapse it uses only its $M_{+,r}$
completed non-null vectors:

$$
V_{b,r}\mid-
\sim
\operatorname{IW}_T
\left(
\nu_{0,r}+M_{+,r},
\Psi_{0,r}+
\sum_{j:r(j)=r,\boldsymbol{\delta}_j\ne0}
\boldsymbol{\beta}_j\boldsymbol{\beta}_j^\top
\right).
$$

Each persistent $V_{b,r}$ is updated once per complete MCMC iteration. A global
special case pools the same sufficient statistic across regions and performs
one update. A fixed regional case supplies $V_{b,r}$ without drawing it and is
the cleanest exact test oracle.

Region-specific pattern probabilities, latent slab covariance, genomic
covariance and descriptive regional summaries are distinct quantities.
$\boldsymbol{\Pi}_r$ describes state frequency; $V_{b,r}$ describes a non-null
latent vector; genomic covariance also depends on realised effects and regional
genotypes.

### 21.3 Regional prototype and low-information behavior

The extended prototype implements persistent regional full-latent and
completed-active covariance states, a shared-global covariance special case,
and fixed regional covariances. With two markers in two regions, exact fixed
regional pattern probabilities were

$$
\begin{pmatrix}
0.46459 & 0.30532 & 0.08180 & 0.14829\\
0.40624 & 0.08260 & 0.24274 & 0.26841
\end{pmatrix},
$$

while the Monte Carlo estimates were

$$
\begin{pmatrix}
0.46662 & 0.29926 & 0.08382 & 0.15029\\
0.40118 & 0.08338 & 0.24926 & 0.26618
\end{pmatrix}.
$$

Separate unknown-covariance regional chains using full augmentation and
null-collapsed conditional completion agreed within prespecified absolute
tolerances of $0.08$ for pattern probabilities and $0.14$ for covariance
elements. With one explicitly declared global Dirichlet prior, a global
covariance, the same marker order, seed, and update schedule, the shared-global
regional wrapper reproduced the ordinary nonregional Cheng sampler exactly for
state, $\boldsymbol{\Pi}$, and $V_b$ draws. All stored regional
$\boldsymbol{\Pi}$ rows and covariance copies were identical. This reduction
does not sum independent regional prior vectors.

An empty declared region under the completed-active sampler draws $V_{b,r}$
from its proper prior and $\boldsymbol{\Pi}_r$ from its Dirichlet prior. A
region with no current non-null markers behaves the same for that iteration.
One completed non-null vector yields a proper posterior because the proper
inverse-Wishart prior supplies the remaining regularization; neither $M_{+,r}<T$
nor single-trait activity causes impropriety when inactive coordinates are
conditionally completed.

Three regularization paths have different meanings:

1. independent proper inverse-Wishart priors are the exact, testable first
   regional model, but can be prior dominated in small regions;
2. fixed shrinkage toward a global covariance can stabilize estimates, but it
   must be specified as a prior or valid hierarchical transition rather than a
   post-draw replacement;
3. a fixed library of covariance templates with region-specific mixture weights
   avoids estimating a free covariance per small region and is a natural later
   mash-like model.

The independent proper inverse-Wishart $V_{b,r}$ and Dirichlet
$\boldsymbol{\Pi}_r$ construction is therefore the first regional **reference**
model, with fixed and shared-global reductions. It should not be promoted as
the unrestricted production default until a partial-pooling or shared-template
policy for low-information regions is selected and partition-invariance tests
replace the current set-dependent global schedule.

## 22. Pattern-by-scale and mash-like relationships

The Cheng model mixes activity masks through $\boldsymbol{\Pi}$. Current
ordinary MT BayesR extends that geometry with a positive component scale
$\gamma_k$ that is shared across activity patterns. If the stored complete
vector is the scaled vector
$\boldsymbol{\theta}_j=\sqrt{\gamma_{k_j}q_j}\,\boldsymbol{\beta}_j$, the
completed-vector covariance statistic is

$$
\sum_{j:\boldsymbol{\delta}_j\ne0}
\frac{
\boldsymbol{\theta}_j\boldsymbol{\theta}_j^\top
}{
\gamma_{k_j}q_j
},
$$

Equivalently, a stored base vector contributes
$\boldsymbol{\beta}_j\boldsymbol{\beta}_j^\top$ without division. The
component and marker scale is removed exactly once; it is never applied to an
already unscaled base vector. Earlier malformed gamma notation is not a valid
parameterization.

A mash-like model instead specifies a library of covariance templates:

$$
\boldsymbol{\beta}_j
\sim
\omega_0\delta_{\mathbf0}
+
\sum_{h=1}^H\sum_{k=1}^K
\omega_{hk}N_T(0,\gamma_kU_h).
$$

Region-specific template weights use

$$
\Pr(z_j=(h,k)\mid r(j)=r)=\omega_{r,hk}.
$$

These are distinct models, not alternative names for $\boldsymbol{\Pi}_r$ and
$V_{b,r}$. Singular trait-specific templates must be evaluated in their active
trait subspace or represented with an explicit mask; they must not be inverted
as nonsingular full-dimensional covariances.

Current support is: general BayesC activity patterns and ordinary global
pattern-by-scale BayesR are public state geometries; current regional
covariance is not coherent; a covariance-template library and regional template
weights are planned research extensions.

## 23. Revised decisions

1. **Authoritative target:** the complete Cheng MT-BayesC$\Pi$ joint model in
   Section 18, with the shared-state model retained as a reduction test.
2. **Pattern $(0,0)$:** integrate out its latent vector in production; retain
   full augmentation only in the reference sampler.
3. **Partially active patterns:** sample the active posterior and conditionally
   complete every inactive coordinate before covariance updating.
4. **$V_b$ update:** use full completed outer products and one degree of freedom
   per non-null marker under production null collapse.
5. **$\boldsymbol{\Pi}$:** use one declared full joint simplex with a positive
   Dirichlet prior; expose initialization separately from prior shape. A shared
   global prior is one vector, whereas regional priors are separately declared
   vectors and are never summed to manufacture the global prior.
6. **State transition:** joint categorical for the reference and initial
   production implementation; coordinate updates require a connected
   one-coordinate state graph and explicit mixing gates before use for larger
   state spaces.
7. **Current regional status:** not coherently implemented.
8. **First regional reference:** persistent independent proper $V_{b,r}$ and
   $\boldsymbol{\Pi}_r$, with fixed and global reductions. Production should
   add declared partial pooling or shared covariance templates.
9. **BayesR reuse:** pattern-by-scale BayesR can reuse completed-active
   augmentation with $1/(\gamma_kq_j)$ sufficient-statistic weighting under
   scaled-$\boldsymbol{\theta}_j$ storage. Trait-specific component geometry
   remains a separately derived future model.
10. **Mash-like roadmap:** introduce covariance-template libraries only after
    the Cheng and regional covariance policies are stable and independently
    tested.

The production recommendation from Section 15 is therefore confirmed and
generalized: use null-collapsed, conditionally completed augmentation with a
joint pattern transition. Cheng full augmentation remains the principal
scientific reference.

## 24. Independent closeout verification

The closeout derivation starts from the complete Cheng joint density and
integrates only the variables removed from the production state space. For a
null pattern, the likelihood is independent of the complete latent vector and

$$
\int N_T(\boldsymbol{\beta}_j;0,V_b)\,
d\boldsymbol{\beta}_j=1.
$$

For a non-null pattern with active coordinates $A$ and inactive coordinates
$I$, the collapsed pattern weight integrates the active marginal
$N(0,V_{b,AA})$. After selecting the pattern, the active posterior is drawn and
the remaining coordinates are restored from

$$
\boldsymbol{\beta}_{j,I}
\mid
\boldsymbol{\beta}_{j,A},V_b
\sim
N
\left(
V_{b,IA}V_{b,AA}^{-1}\boldsymbol{\beta}_{j,A},
V_{b,II}-V_{b,IA}V_{b,AA}^{-1}V_{b,AI}
\right).
$$

The resulting completed vector has exactly its conditional density under the
original multivariate Normal prior. Updating $V_b$ only after every pattern,
active effect, and inactive completion has been refreshed is therefore a valid
partially collapsed Gibbs schedule. Null vectors contribute neither an outer
product nor a degree of freedom. The inverse-Wishart convention in Section 5
then gives $\nu_0+M_+$, not $\nu_0+M$.

Independent enumeration reproduced all four-pattern probabilities and
realised-effect moments reported in Section 19. Full latent and completed
samplers agreed within the prespecified Monte Carlo tolerances, whereas the
coordinate pattern kernel mixed much more slowly in the deliberately
imbalanced null/pleiotropic case. These checks support a joint categorical
transition for the first production implementation. The full-latent Cheng
sampler remains the independent reference rather than the production default.

## 25. Heterogeneous summary-statistic providers

### 25.1 Provider object and marker map

Let $d$ index a dataset/provider and $t$ a trait. A provider supplies

$$
\mathcal D_{dt}
=
\left(
\mathbf s_{dt},
C_{dt},
N_{dt},
\mathcal M_{dt},
\mathcal P_{dt}
\right),
\qquad
\mathbf s_{dt}=X_{dt}^\top\mathbf y_{dt},
\qquad
C_{dt}=X_{dt}^\top X_{dt}.
$$

$\mathcal P_{dt}$ records allele orientation, genotype coding, centering,
standardization, phenotype/effect scale, target population, operator scale,
and summary-error provenance. A declared global marker universe is connected
to each local provider through an injective map

$$
m_{dt}:\mathcal M_{dt}\longrightarrow\mathcal M_{\mathrm{global}}.
$$

The map is part of the likelihood contract. A global marker absent from
$\mathcal M_{dt}$ has no term in that provider likelihood; absence is not
evidence for a zero effect. Alleles must be harmonized to one declared effect
allele before scores and operators enter the sampler.

For independent providers estimating the same trait effect
$\mathbf b_{dt}=\mathbf b_t$, the operator-dependent log likelihood, up to
terms independent of $\mathbf b_t$, is

$$
\ell_{dt}(\mathbf b_t)
=
\mathbf s_{dt}^\top\mathbf b_{t,\mathcal M_{dt}}
-
\frac{1}{2}
\mathbf b_{t,\mathcal M_{dt}}^\top
C_{dt}
\mathbf b_{t,\mathcal M_{dt}},
$$

with any known residual-scale factor applied consistently to both terms. The
joint likelihood factorizes as

$$
p(\{\mathcal D_{dt}\}_d\mid\mathbf b_t)
=
\prod_d p(\mathcal D_{dt}\mid\mathbf b_t).
$$

Its contributions can be accumulated through provider methods without forming
$\sum_d C_{dt}$. Explicit summation is only an algebraic optimization when
providers have the same local marker map and compatible scales. Different
$N_{dt}$, marker sets, LD populations, block structures, and operators are
allowed. Cross-trait borrowing enters through $V_b$ and the marker-state
model; it does not require a common $X^\top X$.

Combining providers requires a common effect interpretation; compatible allele
orientation, genotype coding, centering, standardization, phenotype/effect
scale, and cross-product scale; valid marker maps; and independent
summary-estimation errors. A future cohort-specific decomposition,

$$
\mathbf b_{dt}
=
\mathbf b_t^{\mathrm{shared}}
+
\mathbf b_{dt}^{\mathrm{specific}},
$$

is a distinct multi-cohort or multi-ancestry model and is not part of the first
implementation.

### 25.2 Provider/operator interface

Every provider operator must expose dimension, marker map, diagonal access,
matrix-vector application, quadratic evaluation, and residual-score updates.
The provider-local residual score is

$$
\mathbf r_{dt}
=
\mathbf s_{dt}-\widetilde C_{dt}
\mathbf b_{t,\mathcal M_{dt}}.
$$

The marker-state, conditional-completion, $\boldsymbol{\Pi}$, and $V_b$
policies consume likelihood contributions through this interface and remain
independent of whether $\widetilde C_{dt}$ is dense, CSR, or block eigen.

For block $b$, provider $dt$ owns its own factorization

$$
C_{dt,b}
\approx
Q_{dt,b}\Lambda_{dt,b}Q_{dt,b}^\top,
$$

where $Q_{dt,b}$ is $p_{dt,b}\times r_{dt,b}$,
$\Lambda_{dt,b}$ is $r_{dt,b}\times r_{dt,b}$, and retained rank
$r_{dt,b}$ may differ across providers and blocks. Full rank reproduces the
provider block cross-product, subject only to floating-point eigendecomposition
error. Rank truncation defines an explicit operator-relative likelihood
approximation; it is not an approximation to $V_b$ and is not made exact by a
loose comparison tolerance.

The standalone implementation in `mtblr_provider_operators.R` verifies dense,
CSR, full-rank eigen, and retained-rank application without using production
C++ as an oracle. With distinct provider matrices, sample sizes $120$ and $75$,
and different marker coverage, its heterogeneous log-likelihood was
$0.173500000000$. A full-rank eigendecomposition agreed with the dense operator
to $10^{-12}$; the deliberately rank-one representation agreed exactly with
its reconstructed retained operator but differed from the dense application by
$0.384952573027$. Provider order and eigenblock order were invariant. A
consistent provider-local permutation of marker identifiers, score entries,
effect alleles, cross-product rows and columns, and the induced global map was
also invariant for dense, CSR, and full-rank block-eigen operators. Thus local
order is arbitrary only when every local object moves together. Two
independent providers for one shared trait agreed with a valid explicitly
summed operator. Incompatible coding, allele orientation, and undeclared
overlap failed informatively.

### 25.3 Sample-overlap boundary

The likelihood design has three distinct regimes:

1. **Common-sample individual level.** A common row-aligned genotype/phenotype
   likelihood may use full residual covariance $V_e$.
2. **Heterogeneous independent-provider summaries.** Provider contributions
   factorize; $C_{dt}$ may differ by provider and trait, and genetic borrowing
   is through the prior.
3. **Overlap-aware summaries.** Cross-provider score-error covariance must be
   supplied or identified under a separate contract. Marginal provider
   eigendecompositions do not identify it.

Provider-specific $C_{dt}$, marker-effect covariance $V_b$, individual-level
residual covariance $V_e$, and cross-provider summary-score error covariance
are different objects. None substitutes for another.

## 26. Computational blocks, statistical regions, and annotation groups

Three partitions must remain separate:

- **Computational eigenblocks** partition a provider likelihood operator and
  may change with LD construction or retained rank.
- **Statistical covariance regions** assign markers to prior states $V_{b,r}$
  and possibly $\boldsymbol{\Pi}_r$.
- **Annotation, source, or marker groups** may modify activity-pattern,
  scale-class, covariance-template, or prior-variance probabilities.

An eigenblock is not automatically a covariance region. Changing LD block
boundaries must not silently change the prior. Every global or regional prior
state is updated once per complete MCMC iteration, outside trait, provider,
set, and eigenblock traversal.

The independent inverse-Wishart regional prototype is the proper reference
model and supplies exact empty/no-active reductions. It is not yet the
recommended unrestricted production default: small regions can be dominated
by their priors. The likely production direction is partial pooling toward a
global covariance or a shared library of fixed/pre-estimated covariance
templates with region-specific weights. The global-covariance and fixed-region
reductions remain mandatory test cases.

   $\boldsymbol{\theta}_j$ effects and removes $\gamma_{k_j}q_j$ exactly once.
   A base-vector implementation is equivalent only when it does not divide the
   unscaled outer product. Trait-specific-component BayesR remains future work.
3. One joint pattern simplex and a joint categorical transition are the first
   implementation target.
4. Heterogeneous independent-provider summary likelihoods are a near-term core
   requirement, not a later optional extension.
5. Dense, CSR, and provider-specific block-eigen operators implement the same
   likelihood interface; retained rank is an explicit approximation.
6. Overlapping summary providers require a separate covariance-aware contract.
7. Current set handling is not coherent region-specific covariance.
8. Persistent proper regional states remain the reference, while partial
   pooling or shared covariance-template libraries are the likely production
   model for low-information regions.

## 29. Phase 4a qualification implementation status

The validated null-collapsed, conditionally completed transition is now
implemented in one internal qualification-only vertical slice for exactly two
common-sample traits, packed BED, and supplied fixed full $V_e$. It uses the
canonical four-pattern joint draw, samples the global Dirichlet
$\boldsymbol{\Pi}$ state, and performs exactly one authoritative
inverse-Wishart $V_b$ update from completed non-null latent vectors per
iteration. Null markers have no production latent draw and contribute neither
an outer product nor a degree of freedom. No heuristic covariance replaces
the draw.

This implementation composes the shared resolved-specification,
resource/provider, task-seed, retention, convergence, worker-diagnostic, and
raw-v2 contracts. It does not call or repair the legacy public MT route. Exact
four-pattern algebra, a one-marker enumeration comparison, covariance-
sufficient-statistic reconstruction, and serial/parallel reproducibility are
recorded in
[the Phase 4a checkpoint](blr_phase4a_cheng_mt_bayesc_checkpoint.md). Phase 4b
extends the same internal sampler with an optional authoritative
$\operatorname{IW}_2(\nu_{e0}+N,\Psi_{e0}+E^\top E)$ residual-covariance
transition and preserves fixed mode as a zero-RNG branch; see
[the Phase 4b checkpoint](blr_phase4b_sampled_residual_covariance_checkpoint.md).
The completed-active R sampler remains the independent reference. Public
promotion, summary-statistic MT likelihoods, MT-BayesR, regional covariance, and
covariance templates remain deferred.
